# AdminLab — Sistema de Administración de Máquinas de Laboratorio

Este proyecto es un sistema web desarrollado en **PHP, HTML y CSS** que permite a un administrador gestionar de forma centralizada las máquinas de un laboratorio.  
A través de la interfaz web, el administrador puede **encender, apagar y suspender equipos**, además de administrar usuarios y consultar su historial de uso.

---

## Funcionalidades Principales

**Control de energía de máquinas**
- Encender / Apagar / Suspender cada equipo del laboratorio desde la página web.

 **Gestión de usuarios**
- Crear nuevos usuarios registrados para utilizar las máquinas.
- Ver y administrar la lista de usuarios existentes.

 **Historial**
- Visualización del historial de uso de cada usuario.
- Registro de sesiones y acciones realizadas.

---

| Tecnología | Uso |
